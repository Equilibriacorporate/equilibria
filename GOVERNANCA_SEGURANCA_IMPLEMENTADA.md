# Governanca e seguranca implementadas

Este pacote adiciona controles essenciais para vender o Equilibria com mais seguranca:

- Controle de senha do usuario logado.
- Redefinicao de senha de usuarios pelo RH/Admin.
- Registro de consentimento com versao da politica, hash de IP e navegador.
- Politica de retencao de dados por empresa, configuravel de 30 a 1825 dias.
- Aplicacao manual da retencao para apagar dados antigos.
- Exclusao controlada de dados operacionais da empresa mediante confirmacao `EXCLUIR DADOS`.
- Logs administrativos visiveis para RH/Admin.
- Backup administrativo continua disponivel.

Observacao juridica: estes controles reduzem risco operacional e ajudam na LGPD, mas nao substituem revisao juridica, DPA, politica de privacidade e contrato B2B revisados por advogado.
